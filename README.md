# Yuchu Jiang Personal Website

This site is rebuilt on top of the `al-folio`-style branch from `jialefu/jialefu.github.io`.

## Structure

- Home page content: `_pages/about.md`
- Publications: `_bibliography/papers.bib`
- News items: `_news/`
- Social/contact links: `_data/socials.yml`

## Local Preview

```bash
bundle config set path vendor/bundle
bundle install
./preview.sh
```

Then open `http://127.0.0.1:4000/`.
